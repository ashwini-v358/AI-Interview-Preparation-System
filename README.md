# AI Interview Preparation System

An AI-powered interview preparation platform that helps candidates practice technical interviews, evaluate their answers, and identify areas for improvement.

## Features

- Resume-based interview preparation
- Job description-based skill gap identification
- Personalized technical interview questions
- Interview answer submission and evaluation
- Performance summary with technical accuracy, completeness, and clarity scores
- Interview progress and performance comparison

## Technology Stack

**Backend**
- Java
- Spring Boot
- Spring Data JPA / Hibernate
- REST APIs

**Frontend**
- React
- JavaScript
- Vite
- CSS

**Database**
- H2 for local development
- MySQL configuration for persistent storage

**AI Integration**
- AI API integration for question generation and answer evaluation, where configured

## Project Structure

```text
AI-Interview-Preparation-System/
├── backend/
└── frontend/
```

## Getting Started

1. Clone this repository.
2. Follow the backend setup instructions in `backend/`.
3. Follow the frontend setup instructions in `frontend/`.
4. Configure required environment variables and database settings.
5. Start the backend and frontend applications.

Refer to the respective project folders for detailed configuration and run commands.

## Purpose

This project demonstrates full-stack application development, REST API design, interview workflow management, and AI-assisted candidate feedback.
